# progetto-settimana-3
APPLICAZIONE PER POTER GESTIRE I PROPRI ALLENAMENTI SETTIMANALI:
con funzioni di ordine e categorizzazione degli esercizi in base allo stato contrassegnato.

Metodo usato: creazione di oggetti dinamica con funzioni per creare il singolo esercizio. Array che poi è stato reiterato con un forEach nella funzione rendere. Al click dell'aggiunta esercizio viene fatta la validazione form tramite JS con notifica di errore sopra al form. Modifica esercizio con riporto all'input del form con aggiornamento di stato. Ho usato una variabile per identificarla con gli oggetti confrontandola con l'id dell'oggetto cliccato. Con metodo slice ho sistemato la funzionalità di elimina e filtraggio in base al giorno della settimana. Ricerca live inserita identificando all'input con target value e filtrati con filtered ed includes . Progress bar che tramite ricerche ho collegato all'attributo value in modo tale da renderla dinamica calcolando la proporzione nell'apposita funzione.

Tecnologie applicate:

HTML 5
CSS 3
JS Vanilla

concetti applicati - Manipolazione del DOM - event listener con vari eventi event delegation array methods arrow functions rendering dinamico.
